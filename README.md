# 🛠️ utileria.js

Una solución en JavaScript , libre de dependencias y librerías externas, diseñada para gestionar la validación e integridad de datos en formularios web de registro e inicio de sesión.

---

## 💡 ¿Qué problema resuelve?

En el desarrollo web es habitual rehacer una y otra vez los bloques de código dedicados a comprobar información ingresada por los usuarios. Este proceso suele provocar fallos comunes: mala gestión de caracteres especiales (como acentos o la 'ñ'), errores al calcular edades según el día exacto de nacimiento o la aceptación de credenciales poco seguras.

`utileria.js` agrupa estas comprobaciones en un único módulo ligero y reutilizable. Ofrece un conjunto de funciones enfocadas en recibir datos de entrada y retornar un valor booleano, un número exacto o un texto con formato corregido.
